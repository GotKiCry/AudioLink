## 行为与界面

首页重排为音源与共享控制侧栏、连接地址及连接步骤、设备列表。设备地址、指纹和协商信息按需展开；接收其他主机声音的入口默认折叠。复用 Fluent 主题、背景偏好和既有 IPC，不新增依赖。

中英文统一使用等待连接、正在启动、正在推流、正在暂停、已暂停、音源不可用、启动失败等状态。只有实际发送的设备计入推流数量，等待时不显示旧遥测数字。移除开发里程碑和面向实现者的说明。

设备接入并进入可发送状态后默认自动开始（本版本没有信任筛选，**任何能连上 QUIC 端口的设备接入即按此规则**），等待自动偏好和音源读取完成，不覆盖用户保存的关闭偏好。暂停为当前应用会话的全局意图：新设备、重连、切换自动偏好都不取消暂停；手动恢复才继续共享。无设备时也能预先暂停或恢复等待。退出并重新打开程序后按已保存偏好运行。

启动和暂停共享同一条命令路径；先关闭自动入口，再等待启动完成并停止，避免慢启动越过暂停。重复事件不重复启动，失败不无限重试，断开后允许新一轮自动尝试。晚到的初始化快照不覆盖连接事件。音源可在暂停后切换。

## 限制与未验

- 既有桌面 Rust 外壳仍是单路发送。自动启动串行选择可用设备，不向所有设备同时提交必然返回 busy 的命令；多路桌面采集广播不属于本次改动。
- 浏览器交互使用模拟设备事件，不能作为真实出声证据。尚未连接真实接收设备验证 WASAPI → 局域网 → 播放、后台长时间推流和暂停后的听感。
- 自定义背景的所有颜色组合未逐一验收；对比度记录针对默认实体面板。
