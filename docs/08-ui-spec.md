# AudioLink UI 规格

> 已确认形态：桌面端 **卡片式设备列表 + 状态仪表**；Android 端 **单页（状态卡片 + 节点列表）**；两端均有 **遥测**。
> 设计原则：**状态优先**（任何时刻一眼看出"在推什么、给谁、质量如何"）、**一键可达**（连接/断开/静音不藏二级菜单）、**错误必说人话**（不允许出现"未知错误"）。

---

## 1. 设计语言

| 维度 | 桌面端（React + Tailwind） | Android（Compose Material 3） |
|---|---|---|
| 主色 | 靛蓝 `#4F46E5`（浅色）/ `#818CF8`（深色） | `primary` 同色系 |
| 成功态 | `#16A34A` | `tertiary` |
| 警告态 | `#D97706` | `errorContainer` 变体 |
| 危险/断开 | `#DC2626` | `error` |
| 中性色 | 使用 Tailwind `slate` 系列 | `surface` / `surfaceVariant` |
| 圆角 | 卡片 `12px`、按钮 `8px`、徽标 `9999px` | M3 默认 |
| 间距 | 4/8/12/16/24 栅格 | 4 dp 基准 |
| 字体 | Inter（中英同族），正文 14px、次要 12px、标题 18px | 系统字体，正文 14sp |
| 深色模式 | 跟随系统 + 手动切换 | 跟随系统 + 手动切换 |

**统一状态色语义**（两端一致）：

| 状态 | 颜色 | 文案（中/英） |
|---|---|---|
| 空闲 / 可连接 | 中性灰 | 空闲 / Idle |
| 握手中 | 蓝（脉冲动画） | 连接中 / Connecting |
| 推流中 | 绿 | 推送中 / Streaming |
| 接收中 | 绿（另一图标） | 接收中 / Receiving |
| 降级（丢包/抖动） | 琥珀 | 网络不稳 / Degraded |
| 重连中 | 琥珀（旋转） | 重连中 / Reconnecting |
| 出错 | 红 | 已断开 / Failed |

**组件树**

```
<App>
  <TopBar>                         // 采集设备选择 / 采样率 / 编码档 / 主题 / 设置入口
  <StatusStrip>                    // 本机身份 + 活跃会话汇总 + [遥测] 抽屉开关
  <DeviceGrid>                     // 响应式网格，1–4 列（窗口宽度自适应）
    <DeviceCard/> × N              // 见 2.2
    <AddManualCard/>               // 手工添加
    <EmptyState/>                  // 无设备时的引导
  </DeviceGrid>
  <GroupBar/>                      // 勾选节点 → 建立临时同步组（FR-22）
  <TelemetryDrawer/>               // 右侧抽屉：曲线 + 指标表 + [导出]
  <Toast/>                         // 事件提示（配对请求、连接失败、更新可用）
</App>
```

### 2.2 设备卡片

| 区域 | 内容 |
|---|---|
| 头部 | 平台图标 + 设备名（可双击重命名，本地别名）+ 状态徽标 |
| 中部 | `e2e_latency` · `bitrate` · 丢包（三项指标，等宽数字，避免跳动布局）+ 信号条（3 格，按抖动/丢包着色） |
| 音量 | 滑块 0–100（映射到 `SET_GAIN`，带 `ramp_ms` 平滑）；被对端锁定时显示锁图标与上限 |
| 操作 | 主按钮（连接/断开/取消）+ 静音/取消静音 + `⋯` 菜单（配对信息、延迟补偿、复制诊断信息、忘记设备） |
| 特殊态 | 未配对 → 显示 [配对]；质量差 → 顶部琥珀条"网络不稳，已自动降码率" |

**微交互**：连接中显示进度环；推流中卡片左侧 4px 绿色呼吸条；断开时卡片不消失（保留位置，便于重连）。

### 2.3 配对对话框

```
┌──────────────────────────────┐
│ 与「客厅 R1」配对             │
│                              │
│   请在手机屏幕上确认配对码：   │
│                              │
│        4 8 2 9 1 3           │   ← 大号等宽数字
│                              │
│   或输入手机显示的配对码：     │
│   [ _ _ _ _ _ _ ]            │
│                              │
│  ☑ 记住此设备（加入白名单）    │
│        [取消]   [确认配对]     │
└──────────────────────────────┘
```

- 60 s 倒计时环形进度；失败显示剩余尝试次数（`1003 PAIR_REJECTED`）。
- 双向入口：桌面端可显示码让手机输入 —— 由 `PAIR_REQUIRED{pin_display}` 决定哪端显示。

```
┌────────────────────────────────────────────────────────────┐
│ 遥测  [客厅 R1 ▾]                          [暂停] [导出 ▾] │

│ 端到端延迟 (ms)      ╭─╮                                   │
│  100 ├────────────  │ │                                   │
│   60 ├──────╱╲───╲──╯ ╰╲___                               │
│   20 └────────────────────────────                        │
│                                                            │
│ 指标表                                                     │
│  RTT            3.2 ms      jitter P95   6.1 ms            │
│  丢包           0.10 %      PLC 次数     3                │
│  码率           160 kbps    NACK         0                │
│  时钟偏移       0.8 ms      漂移        -12 ppm            │
│  缓冲水位       38 ms       欠载         0                │
│  P50/P95/P99    62 / 88 / 121 ms                           │
│                                                            │
│ [导出台账 CSV] [导出日志 ZIP（脱敏）]                       │
└────────────────────────────────────────────────────────────┘
```

- 曲线保留最近 5 分钟（1 Hz 采样，滑动窗口）；导出为 CSV（时间序列 + 汇总）。
- 日志 ZIP 内容：应用日志、配置快照（脱敏）、会话统计；**不含音频内容**。

### 2.5 托盘菜单

```
AudioLink  ● 推送中 2 台
├─ 打开主窗口
├─ 全部静音 / 取消静音
├─ 客厅 R1     ✓ 推送中   [断开]
├─ 卧室 手机      空闲     [连接]
├─ ───────────────
├─ 开机自启      ✓
├─ 退出
```

行为：关闭主窗口 = 隐藏到托盘（可设置）；退出时优雅关闭所有会话并发送 `BYE`。

### 2.6 设置页

| 分组 | 项 |
|---|---|
| 音频 | 采集设备、采样率档（48k/44.1k/96k/192k）、编码档（Opus 20ms / Opus 10ms / PCM 无损）、码率上限、声道模式 |
| 网络 | QUIC 端口、发现方式（mDNS/广播/手动）、每设备延迟补偿 |
| 通用 | 语言（中/英）、主题（浅/深/跟随系统）、开机自启、启动后自动连接上次设备、关闭窗口行为、最小化到托盘 |
| 安全 | 信任设备列表（查看/移除）、本机指纹（可复制）、重新生成身份（警告：需重新配对全体） |
| 高级 | 日志级别、遥测保留时长、实验性开关（默认关闭） |

## 3. Android 端（Kotlin + Compose）

### 3.1 单页线框

```
┌─────────────────────────────────┐
│ AudioLink            [设置 ⚙]   │  ← TopAppBar
├─────────────────────────────────┤
│ ╭─────────────────────────────╮ │
│ │ 本机状态卡片                 │ │
│ │ 「我的手机」 fp:8e77d2a4     │ │
│ │ 🟢 接收中 · 来自「书房 PC」  │ │
│ │ 端到端 68 ms · 160 kbps      │ │
│ │ 缓冲 36 ms · 丢包 0.1%       │ │
│ │ ─────────────────────────── │ │
│ │ 🔊 ──────●──────  70         │ │
│ │ [停止接收]                   │ │
│ ╰─────────────────────────────╯ │
│                                 │
│ 附近节点                        │
│ ┌─────────────────────────────┐ │
│ │ 💻 书房 PC         🟢 已配对  │ │
│ │ 推送中给你 · 68 ms           │ │
│ │ [断开]  [静音]               │ │
│ └─────────────────────────────┘ │
│ ┌─────────────────────────────┐ │
│ │ 📱 卧室手机        ⚪ 未配对  │ │
│ │ 同一网络 · 可接收            │ │
│ │ [配对]  [发送本机音频]        │ │
│ └─────────────────────────────┘ │
│                                 │
│ [＋ 手动添加 IP]                │
├─────────────────────────────────┤
│  本机发送源：  ⦿ 关闭  ○ 系统内录  ○ 麦克风   │  ← 底部发送源切换
└─────────────────────────────────┘
```

**发送源切换规则**
- `关闭`：仅接收。
- `系统内录`：API 29+ 可用；不可用时置灰并显示"需 Android 10 及以上"（FR-06）。
- `麦克风`：首次切换触发 `RECORD_AUDIO` 运行时授权（FR-07）。
- 内录启动时弹出系统 MediaProjection 授权界面，App 内前置一屏说明："用于把本机正在播放的声音发送给你选择的设备；AudioLink 不会录音、不会上传。"

### 3.2 常驻通知（FR-36）

```
┌──────────────────────────────────────────┐
│ AudioLink · 接收中                        │
│ 来自「书房 PC」· 68 ms · 160 kbps         │
│ [停止]  [静音]                            │
└──────────────────────────────────────────┘
```

- 通知渠道：`playback`（低优先级、常驻、不可滑除）；
- 前台服务类型：`mediaPlayback`；服务启动即进入前台（**不是**播放时才 `startForeground`）；
- 点击通知动作使用显式 Intent（**禁止**指向 BroadcastReceiver 类的错误用法）。

### 3.3 配对界面

- 作为**响应方**：全屏对话框显示 6 位大号数字 + 倒计时 + "有人在请求连接：书房 PC"；
- 作为**发起方**：数字输入键盘（6 位）+ 错误提示（剩余尝试次数）。

### 3.4 设置页（二级）

| 分组 | 项 |
|---|---|
| 音频 | 输出音量上限、每设备延迟补偿、缓冲档（自动/低延迟/稳定） |
| 网络 | 发现方式、QUIC 端口、Wi-Fi 锁定（仅 Wi-Fi 下工作） |
| 通用 | 语言、主题、省电白名单引导（跳转厂商设置页）、保持屏幕常亮（可选）。**无开机自启**（Android 端不做，见 FR-37） |
| 安全 | 信任设备列表、本机指纹、重新生成身份 |
| 诊断 | 遥测详情页（同桌面端指标）、导出日志、崩溃日志 |

**音频输出提示（FR-41）**：检测到当前输出设备为蓝牙时，状态卡片显示琥珀条：
> 「当前输出为蓝牙设备，延迟会显著增加（100–300 ms）。改用手机扬声器或有线耳机可让 AudioLink 达到 40–110 ms。」

（依据：A2DP/SBC/AAC/LDAC 本体延迟 100–300 ms 属物理限制；LE Audio/LC3 在 Android 13+ 可降至 20–30 ms，检测到 LC3 时不提示。）

### 3.5 无障碍与响应式

- 所有交互控件 ≥ 48 dp；TalkBack 可朗读节点状态与延迟；
- 大字体（1.3×）下状态卡片不裁切（使用可伸缩布局）；
- 平板/横屏：节点列表两列。

## 4. 关键流程与文案

| 场景 | 交互序列 | 文案要求 |
|---|---|---|
| 首次启动 | 生成身份 → 扫描 → 空态引导 → 选中节点 → 配对 → 连接 | 空态："正在搜索同一 Wi-Fi 下的设备…（也可以手动添加 IP）" |
| 发现被隔离 | 3 s 无结果 → 提示"未发现设备" + [手动添加 IP] + [排查帮助] | 帮助页含：同一 Wi-Fi？AP 是否开启客户端隔离？Windows 防火墙放行？ |
| 配对失败 | 显示剩余尝试次数 + 60 s 冷却 | "配对码不正确（还可尝试 3 次）" |
| 连接失败 | 分类提示：超时 / 拒绝 / 版本不匹配 / 未配对 | 版本不匹配 → "对方版本过旧（需要 v2 协议），请一起升级" |
| 网络降级 | 卡片琥珀条 + 遥测标记 | "网络不稳，已自动降到 96 kbps" |
| 自愈 | 状态变"重连中"→ 恢复后 toast | "连接已恢复" |
| 采集源丢失 | 提示 + 自动重试 | "采集设备已断开（可能被拔出），正在重试…" |

**文案规范**：中英双语，短句、动词开头、不用技术黑话（不出现 "socket/RTT/Opus" 于用户可见处，遥测面板除外）。

## 5. 视觉验收清单

- [ ] 深浅模式下所有状态色对比度 ≥ 4.5:1（正文）/ 3:1（大字号）。
- [ ] 卡片指标区使用等宽数字（`tabular-nums` / monospace），刷新时不发生布局抖动。
- [ ] 无"只靠颜色传达信息"的元素（状态额外带图标与文字）。
- [ ] 动画仅在状态变化时触发，频率 ≤ 1 Hz 的持续动画（呼吸条为低频渐变）。
- [ ] 桌面端 1024×640 至 3840×2160 布局不破版；Android 360dp 至 840dp 不破版。
