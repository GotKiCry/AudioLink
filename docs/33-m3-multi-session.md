# M3 · 多会话：共享采集枢纽（一路采集喂 N 台接收端）

> 日期 **2026-09-16**。M3 交付物 1 是「发送端并行推流（≥ 8 目标），每会话独立统计与音量」。
> 本轮把它的**结构**做出来了：采集从「每会话一路」改成**引擎级共享的采集枢纽**。

---

## 1. 为什么共享采集是正确性问题（不是优化）

一台发送端给 N 台接收端推同一路音频时，组内同步的基准是**发送端指定的 epoch + sample_index**。

若每个会话各自开一路采集：读取起点不同、丢样各不同 → 各会话的 seq / sample_index 时间轴彼此错开
几十毫秒量级。接收端按**同一个 epoch** 播放时，这点错位会原封不动加到组内偏差上 ——
而 M3 的验收是「组内 ±10 ms」。

共享采集把「同一帧编号」变成全组公共的起点：**枢纽统一分配 seq / sample_index**，各会话只用不造。

## 2. 交付物

| 层 | 内容 | 位置 |
|---|---|---|
| 采集枢纽 | CaptureHub：一路 CaptureSource → 切片 → **统一编号** → 广播（容量 8 帧，慢会话丢旧帧而非拖住采集） | core/crates/audiolink-engine/src/runtime.rs |
| 每会话编码 | session_encoder_main：订阅共享帧 → **用本会话的 codec/码率**编码 → 交给会话循环发送 | 同上 |
| 生命周期 | 第一个会话启流时创建枢纽，最后一个会话停止时停采集（引用计数）；下一个会话会重建 | 同上 |
| API | Engine::start_send_many(peers) → 每台一份结果（一台失败不影响其它） | 同上 |
| 约束 | 同一引擎内所有会话**必须同帧长**，否则明确报错（枢纽按引擎默认帧长切片） | 同上 |
| 探针 | 封口时刻在**枢纽**记录一次（一帧一次），多会话不会各记一遍 | 同上 |

编码留在会话侧不是偷懒：各会话可以有自己的码率（§8 的自适应按对端丢包各自决策），
而采样时间轴仍然全组共享 —— 两件事互不干扰。

## 4. 那个「发现」的更正（2026-09-16 复核）

上一轮我在这一节写下：**接收端的 peers() 里查不到发起端**，并把它列为待核的疑点。

**复核结论：那是测试时序造成的假象，不是产品缺陷。** 我把断言写在 shutdown 之后 ——
会话都已经关掉了，对端表当然是 0。本轮改成按时序采样（0.5 s → 2 s → 3.5 s → 5 s），
链路上它一直是 **1 条会话、状态在 Streaming/Degraded**，只有关闭之后才变 0（正常清理）。

处置：
- tests/multi_session.rs 增加**正式断言**：链路上时接收端恰好看到发起端一条会话、id 与状态正确；
- 同时加一条**反向断言**：关闭之后对端表必须清干净（否则 UI 上会挂着不存在的设备）；
- 这一节的错误结论在此更正 —— 文档里留着一个假缺陷比没有记录更坏。

教训（也值得留在这）：**断言的位置本身就是结论的一部分**。在 shutdown 之后查表、
在渐变期测稳态、在 priming 前量队列 —— 都是同一类错误。

## 6. 动态加入：运行中第 3 台加入，前两台不中断（2026-09-17 补验）

M3 的验收表有四条：并发、同步、**动态**、时钟。此前：并发由本文档 §3 的 3 台测试覆盖，
同步要真机同期录音，时钟由 `clock_sync` 覆盖 —— **只有「动态」没有任何自动化证据**，
而它恰恰是最容易出问题的：新会话加入时要新建采集订阅、新建编码器、新建 QUIC 会话，
任何一处争用都可能让**已经在跑的会话**停顿。

新增 `core/crates/audiolink-engine/tests/engine/dynamic_join.rs`：

1. 两台接收端先配对、开流、跑 4 s（确认各自确实在出声）；
2. 第三台**在运行中加入**（连接 → PIN → 开流）；
3. 再跑 4 s，量三台各自的**样本增量**。

判据用「接收侧 sink 的样本增量」而不是「状态还是 Streaming」：状态是采样出来的，
断流几百毫秒可能采不到；样本数不增长才是**直接证据**。

### 6.1 实测（2026-09-17）

```text
动态加入：前两台新增 [387840, 387840] 个样本，第三台 382080 个样本
```

理论满额 = 4 s × 48 kHz × 2 声道 = **384 000**。前两台都在满额之上、第三台也接近满额 ——
**第三台的加入没有让前两台掉一个样本**。
