# M5 · 桌面端中英双语（i18n）

> 看板：`[M5] 桌面端中英双语（i18n + 全部界面文案）`。日期 **2026-09-17**。
> 一句话：把 **139 条**界面文案从「散在 JSX 里的中文」变成「一张表 + 一个函数」，
> 并让「漏译」与「漏占位符」都在构建期变红。

---

## 1. 三个「不做」

### 1.1 `t` 是模块级函数，不是 hook

界面里有 139 处文案。若每处都要 `const t = useT()`，改文案就变成了改 16 个组件的样板代码。
这里让组件直接 `import { t }`，语言变化由 App 顶层的 `useLocale()`（`useSyncExternalStore` 订阅）
触发整棵树重渲染 —— `t` 是**渲染期求值**的，所以重渲染即换语言。

### 1.2 缺键是编译错误

中文表用 `as const` 定义键集合，英文表声明为 `Record<MessageKey, string>`：英文少一条，`tsc` 直接报错。
在没有 i18n 框架的前提下，这是唯一能自动验证「翻译完整性」的手段。

### 1.3 不引 i18n 框架

139 条文案、两种语言、没有需要复数/性别的句子 —— 手写表 + 30 行插值函数比引一个运行时依赖更省。
真需要 ICU 复数规则时再加；现在就引进来只是为了「以后可能用到」。

## 2. 覆盖范围

| 项 | 数量 |
|---|---|
| 界面文案 | **139 条 × 2 语言**（`zh-CN` / `en-US`） |
| 改动文件 | 18 个（14 个组件 + `App.tsx` + `types.ts` + `useAudioLink.ts` + `ipc.ts`） |
| 残留中文 UI 文案 | **0**（扫描：非注释行里已无裸中文） |

替换方式：可机械化的部分（字符串字面量 / JSX 属性 / 单独成行的文本节点）用脚本按「中文原文 → 键」
一次替换完；13 处模板串与混合节点手工改。**字典即映射表** —— 脚本直接从 `i18n.ts` 的中文表读原文，
不另维护一份对照表（那迟早会漂移）。

## 3. 三处「常量 → 函数」的改造（最值得记的一条）

`PEER_STATE_LABEL`（`types.ts`）与 `VERDICT_TEXT`（`AlignmentPanel`）原本是**模块级常量**：

```ts
export const PEER_STATE_LABEL: Record<PeerState, string> = { idle: t("state.idle"), ... };
```

模块级常量在**模块加载那一刻**求值一次 —— 也就是说，语言切换后整个界面都变了，只有这几个字不变。
这类 bug 不报错、不崩溃，只是「看起来有点怪」，最容易留在发布版里。两个都改成了函数
（`peerStateLabel(state)` / `verdictText(verdict)`），并在注释里写明为什么不能写成常量。

同类问题还有一处**变量遮蔽**：`TelemetryPanel` 里 `const t = telemetry;`（遥测快照的短别名）会把翻译函数
遮住 —— `t("tm.peers")` 于是被解析成「调用一个遥测对象」。改成 `tele` 之后才编译通过。

## 4. 状态与持久化

- 语言偏好写 `settings.json` 的 `locale` 键（Tauri 命令 `locale` / `set_locale`），与 `autostart` /
  `auto_connect` 同一条路 —— 用户的选择必须跨重启活着；
- 没存过就跟随系统语言（`navigator.language`），并把推断结果写回；
- `set_locale` **只接受** `zh-CN` / `en-US`：设置文件可以被手改，一个 `ja-JP` 不该让界面变成
  「查不到的键都显示键名」，拒掉非法值、前端回落到系统语言；
- 切换顺序是**先立即生效、再落盘**：写盘失败也不该让用户觉得「点了没反应」（真失败会有错误横幅）。

## 5. 护栏：`desktop/scripts/check-i18n.mjs`

接在 `pnpm build` 里（`tsc --noEmit && node scripts/check-i18n.mjs && vite build`），本地与 CI 都会跑。
检查三项：**键集合一致**、**占位符集合一致**、**无空文案**。

为什么需要它：`tsc` 只能保证「英文表键齐全」，**管不了占位符** —— 英文译文里漏写一个 `{name}`，
界面上会静默少一个值，编译期一声不吭。

破坏性验证（护栏自测）：把 `en` 的 `status.local` 改成 `"This device"`（去掉 `{name}`）→ 脚本 **exit 1**；
恢复原文 → **exit 0**。
